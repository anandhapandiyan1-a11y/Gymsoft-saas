USER WORKFLOW
================================================================================
STEP 1: LANDING & REGISTRATION (/register)
  Target: Gym Owners registering their gym onto GymSoft SaaS
  Inputs: Owner Full Name, Gym Name & Code, City & Address, Personal Phone, Business Phone,
           Account Password, SaaS Subscription Tier Selection (PLAN_2K/3K/4K cards)
  Output: Creates Tenant Account + GYM_CODE + Active 2-Day Trial (is_trial_active=True,
  trial_expiry=now+2days)

STEP 2: AUTHENTICATION (& /login)
  Target: ALL roles (SUPER_ADMIN, OWNER, TRAINER, MEMBER)
  Inputs: Mobile Phone + Password
  Output: JWT token, role, user_id, full_name saved in localStorage
  Auto-redirect to appropriate dashboard based on Role

STEP 3: GYM OWNER DASHBOARD (/owner-dashboard)
  Tabbed interface with:
  a) Overview & Settings: Update Gym UPI/GPay ID, Set Custom Monthly Gym Fee,
     view Trial Expiry timer
  b) Trainer Management: Register Gym Trainers, view salaries
  c) Member Management: View/Add Gym Members, toggle fee payment status,
     assign trainers to members
  c) 1-Week Absentee Retention Alert: Red warning table filtering members absent 7+ days
  d) Competition Poster Hub: Upload Bodybuilding/Powerlifting event posters that
     broadcast to ALL SaaS gyms in the network

STEP 4: TRAINER DASHBOARD (/trainer-dashboard)
  - View assigned members list
  - Assign workout routines based on category (BODYBUILDER, FAT_LOSS, MUSCLE_GAIN, etc.)
  - Mark daily attendance for assigned members

STEP 5: MEMBER DASHBOARD (/member-dashboard)
  - Display Gym Name, Assigned Trainer, Monthly Gym Fee
  - GPay / UPI Fee Payment section using Owner's configured UPI ID
  - View assigned workout plans by category
  - View Tamil Nadu All-Gym Shared Competition Poster Feed
  - Mark daily attendance ✅
  - Submit injury feedback to assigned trainer

STEP 6: SUPER ADMIN (/super-admin)
  - Overview of all gyms, subscription plans, active member counts, monthly revenue
  - System metrics and owner feedback management
